# Most common network devices :
- **router** _ connect different networks with each other
- **switch** _ connect devices with each other in the sane network
- **Access point** _ allows a wireless devices to connect to a wired local area network (LAN)
- **Firewall** _ it`s a security device or program that monitor and filter and controls incoming and outcoming traffic in network
- **Modem** _ it`s a device that connects your hosts devices to your internet service provider (ISP)
- **Load balancer** _ it`s a device or a program that distributes traffic across multiple servers to prevent any single server from becoming overloaded
